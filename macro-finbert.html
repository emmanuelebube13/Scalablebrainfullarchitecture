Core Architecture

1. Text Ingestion & Sliding Chunking

Central bank statements (such as FOMC press releases or ECB policy decisions) routinely exceed BERT's 512-token limit. Rather than naive front-truncation which discards critical forward guidance in later paragraphs, ScalableBrainFinBERT executes token-aware sliding window chunking:

CHUNK_SIZE = 450 tokens
OVERLAP = 50 tokens
stride = CHUNK_SIZE - OVERLAP = 400 tokens

Each chunk is evaluated independently through AutoModelForSequenceClassification. Probabilities are synthesized using an arithmetic mean across chunks, while peak dispersion is captured as the system's maximum uncertainty flag.

Mathematical Formula

2. Sentiment & Shannon Entropy

For any text segment producing Softmax probability distribution \(P = [p_{\text{neg}}, p_{\text{neu}}, p_{\text{pos}}]\):

Net Sentiment: \(S = p_{\text{pos}} - p_{\text{neg}}\)
Bounded in \([-1.0, +1.0]\). Neutral probability dampens extreme swings without skewing directional bias.
Normalized Dispersion: \(H(P) = -\sum_{i} p_i \log_2(p_i) \;/\; \log_2(3)\)
Bounded in \([0.0, 1.0]\). \(H \approx 0\) represents total model certainty (unanimous consensus). \(H > 0.85\) flags maximum semantic conflict / ambiguous central bank signals.

# Shannon entropy calculation normalized by log2(3)
@staticmethod
def _shannon_entropy(probs: np.ndarray) -> float:
    probs = np.clip(probs, 1e-12, 1.0)
    entropy = -np.sum(probs * np.log2(probs))
    return entropy / MAX_ENTROPY

# Sliding-window token chunking
@staticmethod
def _chunk_text(text: str, chunk_size: int = 450, overlap: int = 50) -> List[str]:
    tokens = tokenizer.encode(text, add_special_tokens=False)
    if len(tokens) <= chunk_size:
        return [text]
    chunks = []
    for i in range(0, len(tokens), chunk_size - overlap):
        chunk_tokens = tokens[i : i + chunk_size]
        chunks.append(tokenizer.decode(chunk_tokens, skip_special_tokens=True))
    return chunks
