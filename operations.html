Operations & Manual Ingestion

Commands and templates for running manual data updates and querying the Postgres database.

1. Manual Python Commands for Ingestion

The ingestion pipeline can be run manually to backfill data or troubleshoot gaps. Run these from the scalable-brain project root directory.

Command Description
python src/layer0/ingest_data/ingest_oanda_prices.py Full ingestion (All supported timeframes and assets).
python src/layer0/ingest_data/ingest_oanda_prices.py --granularity M30 Specific Timeframe (e.g., M30 only).
python src/layer0/ingest_data/ingest_oanda_prices.py --symbol EUR_USD Specific Asset (e.g., EUR_USD only).
./shell/cron_daily_ingest_and_signals.sh Daily Cron execution (Prices + Signals).
./shell/cron_oanda_ingest_saturday.sh Saturday full multi-timeframe batch ingestion.


2. SQL Templates for Fact_Market_Prices

Run these in pgAdmin to verify and analyze the price data.

Check Latest Ingested Data per Timeframe

SELECT 
    a."Symbol", 
    p."Granularity", 
    MAX(p."Timestamp") as latest_candle_time,
    COUNT(*) as total_candles
FROM "Fact_Market_Prices" p
JOIN "Dim_Asset" a ON p."Asset_ID" = a."Asset_ID"
-- Uncomment to filter by granularity:
-- WHERE p."Granularity" = 'M30'
GROUP BY a."Symbol", p."Granularity"
ORDER BY a."Symbol", p."Granularity";

View the Most Recent 100 Candles for an Asset

SELECT 
    a."Symbol", 
    p."Granularity", 
    p."Timestamp", 
    p."Close", 
    p."Volume"
FROM "Fact_Market_Prices" p
JOIN "Dim_Asset" a ON p."Asset_ID" = a."Asset_ID"
WHERE a."Symbol" = 'EUR_USD' AND p."Granularity" = 'H1'
ORDER BY p."Timestamp" DESC
LIMIT 100;
